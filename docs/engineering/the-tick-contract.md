### The tick contract

`tick(state, orders, world)` in `src/sim/tick.ts` plays one day. It never changes its input. It copies the state, lapses trade invitations contradicted by valid queued war orders or the queued spending's military reserve, applies the orders in the given order, then runs `SYSTEMS` in list order on the copy, and returns `{ state, rejected, events }`. The preflight never executes the war or spending early: it only withdraws invitations before consent can charge an inviter. Every order handler and every system receives the same `world`. Inside a tick, orders and systems change that copy in place. Outside the rules, a state is frozen once a tick returns it. The clock, the panels, and the renderer can keep and compare references to it without copying, and the renderer can draw between the previous and the current day.
